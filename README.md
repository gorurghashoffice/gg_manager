## APK baniye nenar niyom
1. Ei zip-er shob file GitHub repository-te upload korun (`.github` folder shoho).
2. Repository-r **Actions** tab -> **Build APK** -> **Run workflow**.
3. 5-8 minute pore run sesh hole oi run-e click kore niche **Artifacts** theke `GG-Manager-APK` download korun.
4. Zip khule `app-debug.apk` phone-e install korun (Android-e "Install unknown apps" allow korte hobe).
